☁️ Сохранение и перенос данных

Без настройки облака прогресс хранится в браузере. Чтобы открыть тот же прогресс на телефоне и компьютере, настрой облачное сохранение через Supabase (бесплатный тариф подходит для личного проекта) и войди в один аккаунт на всех устройствах. Инструкция — в README.md.

Важно: GitHub Pages и Vercel сами по себе не синхронизируют данные между устройствами. Для облачной синхронизации нужен отдельный сервис хранения.

🔐 Общая учётная запись

Чтобы прогресс был одинаковым на телефоне и компьютере, войди под одним и тем же email на обоих устройствах. Один аккаунт — одна общая запись прогресса.
